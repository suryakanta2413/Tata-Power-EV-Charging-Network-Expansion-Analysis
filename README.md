# Tata-Power-EV-Charging-Network-Expansion-Analysis
An end-to-end Business Intelligence project delivering strategic infrastructure recommendations for India's EV charging ecosystem — spanning network saturation, highway corridor gaps, charger performance, and high-ROI expansion opportunities.

📌 Project Overview
This project analyses 5 real-world datasets across 14 Indian states to answer critical infrastructure questions:

Which cities are critically underserved with zero or insufficient charging stations?
Where are highway corridors dangerously exposing EV drivers to range anxiety?
Which charger types generate the most revenue — and by how much?
Which expansion sites offer the highest ROI with fastest payback?

The pipeline covers everything from raw Data → Excel- Cleaning → SQL extraction → interactive Power BI dashboards.

🧠 What I Built
🗃️ SQL — Structured Business Queries
Designed queries to extract targeted insights, including:

EV registration density by city and state
Station utilisation rates and overload identification
Charger type revenue comparison across 1,500 sessions
Highway corridor gap analysis across 80 national highways
ROI ranking of 200 expansion candidate sites

📊 Power BI — Interactive Dashboard
Built a multi-page dashboard visualising:

EV registration growth by city and state
Station utilisation heatmaps and overload alerts
Charger type revenue breakdown and session performance
Highway corridor gap maps with severity classifications
Expansion site ROI rankings and financial projections
